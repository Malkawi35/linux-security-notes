# linux-security-notes

Visual learning notes from a cybersecurity student. Each post is one concept, one diagram, a few sentences in my own words.

## The rule

**Concepts, not solutions.** Nothing here is a walkthrough, a password, or a spoiler for any wargame or lab. The point is understanding how things work — if a post would ruin the challenge for someone else, it doesn't get published.

## Cadence

One genuine post per week. Small and real beats big and rushed.
